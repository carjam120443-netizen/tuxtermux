# DNF compatibility

This directory is reserved for DNF/RPM package-manager compatibility in TuxTermux.

## Status

🚧 Experimental / planned.

DNF is **not yet fully integrated** with the TuxTermux environment. Future work may provide an isolated RPM userspace so DNF can coexist with the native Termux `apt`/`pkg` environment without replacing or breaking it.

The goal is package-manager compatibility, not pretending that Fedora packages are directly interchangeable with native Termux packages.
